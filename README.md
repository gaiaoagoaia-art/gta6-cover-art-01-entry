Turn your photos and a caption into multi-panel GTA-style poster cover art,
and export it as a PNG to share. Everything runs offline in the browser —
photos never leave your machine.

## How it works

1. **Upload photos** (or load the bundled samples). One photo can fill every
   panel, or each panel can hold a different photo.
2. **Pick a layout** — 4-panel grid, hero + 3, full-bleed single, 9-panel
   grid, tilted snapshot strip, or story/portrait.
3. **Crop and position** — drag inside the preview to pan a panel, use the
   zoom slider per panel.
4. **Grade it** — Sunset, Neon, Vice, Golden Hour, or Noir. Grades are
   gradient maps applied to the exported pixels (canvas lookup tables),
   not CSS filters.
5. **Write the caption** — main title in Anton with a sunset-gradient fill
   and dark outline, subtitle in Pacifico neon script, plus a badge ribbon
   and a heat star meter.
6. **Export PNG** in 1080×1080, 1080×1350, or 1920×1080 — one click each,
   or all three at once. Undo/redo covers every edit.

## Run it

Serve `app/` with any static server and open `index.html`:

```sh
cd app
python3 -m http.server 8080
```

Then open `http://localhost:8080`. No network requests, no build step.

## Deterministic screenshot scenes

The editor understands `?shot=` scenes for reproducible renders:

- `?shot=cover&photo=boulevard&caption=SUNSET%20HEIST&layout=hero3&grade=sunset&size=1920x1080`
  renders the export canvas full-frame at the export size.
- `?shot=editor&photo=boulevard&caption=SUNSET%20HEIST` shows the editor
  with a sample photo loaded.

See `shots.json` for the four screenshot scenes used for this entry.

## Files

- `app/index.html` — the page (loads only local files)
- `app/src/cover.js` — cover renderer: layouts, gradient-map grades,
  lettering, halftone, grain, vignette, export
- `app/src/main.js` — editor wiring: upload, drag/zoom, caption inputs,
  undo/redo, exports, `?shot=` scenes
- `app/style.css` — editor styling
- `app/fonts/` — Anton and Pacifico (SIL Open Font License, OFL texts
  included)
- `app/samples/` — two AI-made sample photos, free to use
- `main.ts` — entry program: copies `app/` + `screenshots/` to the output
  directory and writes `dossier.json` with the kit library

## Originality

All artwork is generated by this app from the user's own photos. No
Rockstar Games logo, wordmark, official artwork, character, or font is
used. Titles are invented ("Sunset Heist", "Boulevard Queen",
"Neon Shore") — no game branding words appear anywhere.
